# Programação Orientada a Objetos (POO) ☕

Repositório dedicado aos estudos, exercícios e projetos práticos da disciplina de Programação Orientada a Objetos. O foco principal é a aplicação de conceitos como classes, objetos, encapsulamento, herança e polimorfismo.

## 📁 Estrutura do Repositório

Atualmente, o repositório está organizado da seguinte forma:

* **Exercicios Introdutorios**: Contém os primeiros códigos desenvolvidos para fixação da sintaxe básica e lógica fundamental.

## 🚀 Tecnologias Utilizadas

* **Linguagem**: Java
* **Controle de Versão**: Git e GitHub
* **Ambiente de Desenvolvimento**: Terminal Linux / Windows

## ⚙️ Como executar localmente

Para compilar e rodar os códigos na sua máquina, é necessário ter o **Java Development Kit (JDK)** instalado.
